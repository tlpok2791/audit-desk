네이버 발행 대기

변환이 끝난 원고입니다. 제목·본문·태그를 복사해 스마트에디터에 붙여넣으세요. 발행 후 "발행 완료"를 체크하면 마무리 명령이 나옵니다. 자동 발행은 하지 않습니다.

원고는 이렇게 만들어집니다

  • 서류를 work/docs/ 에 넣고 /from-docs <폴더> — 판독해서 초안을 만듭니다
  • 초안을 읽어 본 뒤 /naver-ready <초안> — 발행용 변환과 준법 점검이 동시에 돕니다
  • 마크다운을 걷어낸 네이버 규격으로 나오고, 검토가 필요한 대목은 표시됩니다
  • 전부 Claude 에이전트가 합니다. 별도 API 키가 필요 없습니다
