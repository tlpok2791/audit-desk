# config/coa-map/ — 회사별 COA 매핑

회사 계정과목명을 표준 COA(`config/standard-coa.json`)에 붙인 결과를 회사코드별로 둔다.

```
config/coa-map/MAPLE.json
config/coa-map/HANBIT.json
```

## 왜 필요한가

회사마다 회계프로그램이 다르고 계정과목명도 제각각이다.
"외상매출금 / 받을어음 / 매출채권"이 모두 표준 COA의 `1200 매출채권` 하나로 모여야
정산표가 회사와 무관하게 같은 모양이 된다.

## 어떻게 만들어지나

탭1의 2단계 "표준 COA 매핑" 화면에서 만든다.

1. 유사도로 후보를 제안한다. **자동 확정하지 않는다** — 확정은 사람이 한다.
2. 미매핑이 하나라도 남으면 정산표를 만들 수 없다.
3. "매핑 저장 (내려받기)" 를 누르면 `<회사코드>.json` 이 내려받아진다.
   그 파일을 이 폴더에 넣고 커밋하면 **다음 기수에는 신규 계정만 확인**하면 된다.

## 형식

```json
{
  "회사코드": "MAPLE",
  "version": 1,
  "updated_at": "2026-08-23T22:25:29.246Z",
  "entries": [
    { "회사계정코드": "101", "회사계정과목명": "현금", "표준COA코드": "1100" },
    { "회사계정코드": "103", "회사계정과목명": "보통예금", "표준COA코드": "1100" }
  ]
}
```

여러 회사 계정이 같은 표준 COA를 가리켜도 된다 (위 예에서 현금·보통예금 → 1100).

화면은 회사계정코드로 먼저 찾고, 못 찾으면 계정과목명으로 찾는다.
그래서 회계프로그램을 바꿔 코드가 달라져도 이름이 같으면 매핑이 이어진다.

## 불러오는 순서

1. `config/coa-map/<회사코드>.json` — 여기 커밋해 둔 것
2. 브라우저 보관본 — 아직 파일로 안 옮긴 것

## 주의 — 공개 범위

이 폴더는 커밋되어 정적 사이트로 함께 배포된다.
계정과목명은 대체로 민감하지 않지만, 회사 고유 계정과목명이 드러난다는 점은 알고 쓴다.
금액은 들어가지 않는다 (금액은 `work/` 에만 있고 그 폴더는 커밋되지 않는다).
